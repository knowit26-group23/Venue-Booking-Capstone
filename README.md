# 📖 Project Overview

The **Venue Booking Management System** is a web-based application developed to simplify venue booking and event management through a secure, scalable, and user-friendly platform.

Built using **Spring Boot Microservices**, **React.js**, **JWT Authentication**, and **MySQL**, the system enables users to search and book venues, venue owners to manage venues and bookings, vendors to manage services, and administrators to oversee platform operations.

This project is being developed as part of the **CDAC PG-DAC Capstone Project**.

---

# 🎯 Objectives

- Develop a secure and scalable venue booking platform.
- Implement a Microservices Architecture using Spring Boot.
- Secure REST APIs using JWT Authentication and Spring Security.
- Build a responsive and intuitive frontend using React.js.
- Maintain a modular and extensible application design.

# 🔐 Microservices

The backend follows a **Microservices Architecture** consisting of the following independent services:

| Service | Responsibility |
|----------|----------------|
| **Authentication Service** | JWT Authentication & Authorization |
| **User Service** | User Management, Bookings, Reviews & Dummy Payments |
| **Owner Service** | Venue & Time Slot Management |
| **Vendor Service** | Vendor Services & Package Management |
| **Admin Service** | User, Owner & Vendor Administration, Reports |
